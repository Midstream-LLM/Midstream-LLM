## 1. 全局观：大模型本质上只做一件事

### 猜下一个字

大模型的核心任务只有一个：**猜下一个字**。给它「天下大势，分久必」，它预测下一个字大概率是「合」。所有能力——续写、问答、翻译——底层都是这一个动作反复执行。

这个任务叫**自回归语言建模（autoregressive language modeling）**。"自回归"就是"用自己之前生成的，预测下一个"。

### 怎么变成可训练的数学问题

输入和标签只错开一位：

```
输入序列：  天  下  大  势  ，  分  久  必
              ↓  ↓  ↓  ↓  ↓  ↓  ↓  ↓
模型预测：  下  大  势  ，  分  久  必  合   ← 每个位置都预测"下一个字"
真实答案：  下  大  势  ，  分  久  必  合   ← 错位一个字，就是 label
```

模型在每个位置输出一个"下一个字的概率分布"，和真实下一个字比，算**交叉熵损失**，反向传播更新参数。这就是整个训练循环的核心。

## 2. 整体数据流

从原始文本到 loss，数据经过这些环节：

```
原始文本 "天下大势，分久必合"
    │  ① tokenizer（ccc-bbpe-32k，已训好）
    ▼
token ids  [1234, 567, 89, ...]          ← 整数序列
    │  ② 拼成 batch，padding 对齐
    ▼
input_ids  shape: [batch, seq_len]       ← 例如 [4, 2048]
    │  ③ embedding 层：每个 id → 一个向量
    ▼
hidden states  shape: [batch, seq, d_model]   ← [4, 2048, 704]
    │  ④ 过 N 个 Transformer Block（核心）
    │     ┌─────────────────────────┐
    │     │  Block 1                │
    │     │  Block 2                │     × 30 层（200M 配置）
    │     │  ...                    │
    │     │  Block 30               │
    │     └─────────────────────────┘
    ▼
hidden states  shape: [batch, seq, 704]      ← 仍是这个维度
    │  ⑤ final norm + lm_head（线性层 → 词表大小）
    ▼
logits  shape: [batch, seq, vocab_size]      ← [4, 2048, 32768]
    │  ⑥ 和错位一位的 label 算交叉熵
    ▼
loss  → backward → optimizer 更新参数
```

**关键维度记住：**
- **d_model = 704**：模型内部所有向量的"宽度"，贯穿全程的主维度。
- **seq_len = 2048**：一次处理 2048 个 token。
- **vocab_size = 32768**：词表大小，最后一层映射回这么多字的概率。
- **tie_word_embeddings**：embedding 和 lm_head 共享权重（输入端把字变成向量、输出端把向量变回字概率，用同一套参数）。

## 3. Transformer Block 结构

每一层 Block 内部结构相同，采用 **pre-norm 残差结构**：

```
输入 x
  │
  ├──────────────────┐
  │ RMSNorm          │
  │ Self-Attention   │   ← ① 让每个字"看到"上下文其他字（跨位置）
  └──────────────────┘
  │  (与 x 相加，残差)
  ▼
  ├──────────────────┐
  │ RMSNorm          │
  │ SwiGLU FFN       │   ← ② 对每个位置独立做非线性变换（逐位置）
  └──────────────────┘
  │  (残差相加)
  ▼
输出（送入下一层）
```

**两个关键设计思想：**

1. **残差连接**（绕过子层的旁路 `+x`）：让信息能"直达"深层，避免梯度消失。没有它，30 层根本训不动。源自 ResNet。
2. **pre-norm**（先归一化再做运算）：归一化放在子层前面。让训练更稳定。Qwen3/Llama 系都是这个结构。

每个 Block 做两件事：
- **Attention**：让序列里的每个字去"注意"其他字，融合上下文信息——**信息跨位置流动**。
- **FFN**：对每个位置独立地做一次非线性变换——**逐位置加工**。

> 类比：Attention 像开会（收集别人的信息），FFN 像会后独立思考（消化提炼）。30 层交替 = 开 30 轮会，每轮先交流再消化，理解层层加深。

## 4. 多头注意力：头数、头宽，为什么乘起来等于 704

### embedding 是一张"信息卡片"

经过 embedding 之后，序列里每个字都变成了一个 704 维的向量。704 个数字是这个字的"特征档案"。但**没有任何一个维度被预先指定含义**——初始是随机的，含义在训练中长出来。

### "多头"是什么意思

**多头注意力 = 把 704 维的卡片切成 11 份，每份 64 维，每一份交给一个"头"独立处理。**

```
「分」的 704 维向量
┌──────┬──────┬──────┬─────────┬──────┐
│ 头1  │ 头2  │ 头3  │  ...    │ 头11 │
│ 64维 │ 64维 │ 64维 │         │ 64维 │
└──────┴──────┴──────┴─────────┴──────┘
   11 × 64 = 704
```

**为什么要切？** 如果只有一个头，模型只能学到一种关注模式。切成多个头，每个头可以独立学习不同的关注视角（反义对应、修饰关系、标点停顿……）。多个视角拼回来，信息更丰富。

### 为什么 11 × 64 刚好等于 704

**不是物理定律，是设计约定，而且很自然。** 两层原因：

**第一层（为什么必须相等）**：为了让 attention 能塞进残差结构。`Attention(x)` 的输出必须和 `x` 维度相同才能相加。x 是 704 维，所以 attention 输出也得是 704 维。11 个头的 64 维输出拼回去正好 704——**为了让输入输出维度闭环。**

**第二层（为什么偏偏是 11 和 64）**：是凑出来的：
- `head_dim = 64` 是先选定的：GPU 运算友好的尺寸，接近 2 的幂。
- `d_model = 704` 是为了凑 200M 参数量反推出来的。
- 既然 d_model=704、head_dim=64，那 `heads = 704 / 64 = 11`。

> 11 这个"丑数字"不是设计精华，是约束求解的副产物。真正被精心选的是 head_dim 和 d_model，头数是被除出来的。到了 600M 配置，d_model=1536、head_dim=128，heads=12，就漂亮了。

**一句话：d_model 是信息总通道宽度，多头是把这个通道切成几路并行处理，切完拼回去还得是原宽度。**

## 5. Attention 机制详解：Q/K/V 与 causal mask

### Attention 要解决什么问题

每个字一开始只知道自己（自己的 embedding），不知道上下文。但「合」这个字的意思，取决于前面是"分久必合"还是"百年好合"。Attention 的任务是：**让每个字去"看"其他字，把上下文信息吸收进自己的向量里。**

### Q、K、V 三个角色

每个字通过三个不同的可学习线性变换（W_Q、W_K、W_V），生成三样东西：

| 角色 | 含义 | 类比 |
|---|---|---|
| **Query (Q)** | "我想找什么样的信息" | 图书馆的检索词 |
| **Key (K)** | "我能提供什么信息" | 每本书的标签 |
| **Value (V)** | "我实际的内容" | 书的正文 |

匹配过程：**用我的 Query 去和所有人的 Key 比对（点积 = 相似度），越匹配的人，我越多地吸收他的 Value。**

### 手算例子：「分久必合」中「合」的注意力

**第 1 步：算「合」对每个字的关注度分数**（Q · K 点积）：

```
合的Q · 分的K = 2.1   ← 和"分"很匹配！
合的Q · 久的K = 0.3
合的Q · 必的K = 0.5
合的Q · 合的K = 1.0   ← 自己
```

**第 2 步：softmax 把分数变成权重**（加起来=1）：

```
分:0.62   久:0.05   必:0.07   合:0.26
```

**第 3 步：用权重加权求和所有人的 Value**：

```
合的新向量 = 0.62×分的V + 0.05×久的V + 0.07×必的V + 0.26×合的V
```

现在「合」的向量里大量融入了「分」的信息。4 个字每个都这么干一遍（并行计算），整条序列的信息就互相融合了。

### Causal mask：为什么必须有

处理「分」（第 1 个字）时，它**只能看自己**，不能看「久必合」。因为训练时整条序列是一次性喂进去的，但任务是"猜下一个字"——如果「分」能偷看到「合」，就等于提前知道了答案，训练失效。

```
        分  久  必  合
分  →   ✓   ✗   ✗   ✗     ← 分只能看自己
久  →   ✓   ✓   ✗   ✗
必  →   ✓   ✓   ✓   ✗
合  →   ✓   ✓   ✓   ✓
```

**causal mask 用一个上三角遮罩，强制每个位置只看过去，模拟真实的自回归生成过程。**

## 6. FFN 详解：1856 个模式探测器

### Attention 和 FFN 的分工

- **Attention**：让「合」去看「分」——**跨位置**交换信息。
- **FFN**：对「合」的向量单独做变换，**完全不看其他字**——**逐位置**处理。

### SwiGLU 结构

配置用 SwiGLU，比普通 MLP 多一条"门控"支路：

```
         输入向量 x (704维)
          │
     ┌────┴────┐
     ▼         ▼
   gate 支路  up 支路        ← 两个独立的线性层，都升到 1856 维
   silu(g)    u
     │         │
     └────×────┘             ← 逐元素相乘（门控：决定放行多少）
          │
        down 线性层           ← 降回 704 维
          │
        输出 (704维)
```

三个矩阵 W_gate、W_up、W_down 全是可学习参数。

### 核心视角：1856 个"模式探测器"

把 1856 维中间层看成 1856 个独立的"模式探测器"。每个探测器的参数定义了"我对什么输入模式敏感"：

- 第 37 号可能检测"对偶结构"（A-久-必-B）
- 第 1024 号可能检测"聚合/统一语义"
- 第 888 号可能检测"史书文体"

silu(gate) 像开关——模式出现就打开，没出现就关闭。W_down 把 1856 个探测结果加权组合回 704 维。

> 这不是比喻——人们真的在训练好的模型里找到了这种探测器（GPT-2 里有专门对"爱情"或"法律条文"激活的神经元）。这个领域叫**机制可解释性（mechanistic interpretability）**。

## 7. 核心认知：含义是涌现的，不是设计的

这是理解深度学习最根本的认知转换。

### 没有人给维度"分配"含义

embedding 的 704 维在训练前没有任何含义，是随机初始化的数字。含义是训练过程中被梯度下降一点点塑造出来的。

### 头不是"随机分组"

注意力头切的不是 embedding，是投影后的 Q/K/V。W_Q、W_K、W_V 是**可学习参数**——模型在训练中自己调整这些矩阵，**决定把哪些信息路由到哪个头**。分组结构（11×64）是固定的，但每个头看什么内容是模型学出来的。

### 会不会两个头学到一样的东西？

**诚实回答：会，但不严重。**

推动分化的力量：
- 初始化不同（起点不同）
- 冗余对 loss 不利（梯度下降倾向找到分工合作的配置）
- 经验证据：训练好的模型里头确实会专精化

但也要坦白：不是完美分工，真实模型里存在冗余头甚至"死头"。这是已知现象和研究热点（"头剪枝"）。

### 谁来"保证"FFN 合理？

**没有任何人、任何机制"保证"它合理。** 过程是：

1. **起点**：所有参数随机初始化，模型什么都不懂。
2. **压力**：喂数据，让它预测下一个字，猜错了产生 loss 惩罚信号。
3. **塑造**：梯度下降根据惩罚微调所有参数。
4. **重复几十亿次**：在 41 亿 token 上反复这个过程。
5. **涌现**：参数自己组织成了有用的形态。

> **类比进化**：眼睛不是工程师设计的，是亿万年选择压力从随机突变里筛出来的。FFN 里的特征探测器也一样——不是设计的，是几十亿 token 的预测压力从随机参数里雕塑出来的。

### 诚实的边界

我们至今没有严格的理论证明"这套架构 + 梯度下降一定能学出好表示"。我们知道的只是经验事实：架构提供**容量**，数据提供**信号**，梯度下降提供**优化压力**，三者凑齐，有用的结构就**涌现**了。

### "模型能学" ≠ "设计无所谓"

大部分东西（embedding 含义、头分工、FFN 探测器）靠涌现，设计只需提供容量。但**少数组件的设计真正重要**——位置编码就是其中之一。不同注入方式的数学性质，决定了模型能用它做到什么程度的事（尤其是长度外推）。RoPE 的旋转不是随便选的。

## 8. RoPE 位置编码：旋转注入相对位置

### 问题：Attention 是"瞎子"，看不见顺序

点积这个操作对顺序无感。「分久必合」打乱成「合必久分」，每一对字之间的 Q·K 分数完全不变。但古汉语里顺序极其重要（"分久必合"和"合久必分"意思相反）。**必须把位置信息注入 attention。**

### RoPE 的核心：旋转产生角度差

**2 维情形**：每个字的 Q/K 向量，根据位置旋转一个角度。位置越靠后，转的角度越大。

```
位置 1 的「分」：Q 向量旋转 1×θ
位置 4 的「合」：Q 向量旋转 4×θ
```

K 向量也按同样规则旋转。

### 精确公式（纠正直觉偏差）

任何向量用"模长 + 方向角"表示：`Q = |Q| × (方向角 φ_Q)`。

**不旋转时**的点积（全是内容，和位置无关）：

```
Q · K = |Q| |K| cos(φ_Q − φ_K)
```

**加了 RoPE 旋转后**（位置 m 转 mθ，位置 n 转 nθ）：

```
R(mθ)Q · R(nθ)K = |Q| |K| cos( (φ_Q − φ_K) + (m−n)θ )
                                ─────────  ─────────
                                  内容部分    位置部分
```

**RoPE 做的唯一一件事：把 (m−n)θ 这个相对位置项，塞进余弦函数里，和内容角度加在一起。**

- **内容**（|Q|、|K|、φ_Q−φ_K）：决定"这两个字本身有多相关"。
- **位置**（(m−n)θ）：在内容相关性基础上做**调制**——"隔这么远，相关性要打折扣/加分"。

> **位置不是替代内容，是在内容之上叠加一层距离调制。**

### RoPE 保证什么，不保证什么

**保证的**：注意力分数是相对位置的函数，不是绝对位置的函数。公式里只有 (m−n)，没有单独的 m 或 n。如果两个字都往后挪 100 位，相对距离不变，分数一模一样。这叫**相对位置编码**。

**不保证的**：不保证"位置可被唯一解码"。模型从来不需要从分数里"读出"位置——它只需要分数在正确的距离上高、在错误的距离上低。模型通过学习 W_Q、W_K 的方向来实现这一点。

> **RoPE 不让模型"知道"位置，它让模型的注意力分数"感受"到相对距离。感受，不是认知。**

### 推广到 64 维：32 对不同转速的指针

把 64 维两两配对，分成 32 对 2 维平面，每一对独立旋转，但**转速不同**：

```
┌────────┬────────┬────────┬───────────┬────────┐
│ 第1对  │ 第2对  │ 第3对  │   ...     │ 第32对 │
│ 转得快  │ 转得快  │ 中等    │           │ 转得慢  │
└────────┴────────┴────────┴───────────┴────────┘
```

- **转得快的对**：对相邻位置敏感——捕捉**局部**关系。
- **转得慢的对**：对远距离敏感——捕捉**长程**关系。

> 像时钟：秒针转得快、分针中等、时针慢。32 对就是 32 根不同转速的"位置指针"，合起来能同时感知"紧挨着"和"隔了 2000 个字"。

### rope_theta：控制最慢指针的转速

- 200M 配置：`rope_theta = 10000`（经典值）
- 600M/1.5B 配置：`rope_theta = 1_000_000`（Qwen3 的选择，为长上下文留余量）

数字越大，最慢的指针转得越慢，能区分更远的距离（角度差不会"绕一圈绕回来"重复）。

### RoPE 无可学习参数

旋转角度完全由位置和 rope_theta 公式决定，是固定的数学操作。模型要学的是 W_Q、W_K（怎么利用这个旋转机制）。**旋转机制是人设计的（骨架），内容表示是模型学出来的（血肉）。**

## 9. RMSNorm 与训练稳定性

### 为什么需要归一化

Transformer 有 30 层，每层都在做矩阵乘法、相加。如果每层把数字稍微放大（乘 1.1），30 层后 1.1³⁰ ≈ 17 倍，数字冲到 inf——**梯度爆炸**。反过来乘 0.9，0.9³⁰ ≈ 0.04——**梯度消失**。

归一化的作用：**每层出口处强制把数字拉回均值 0、方差 1 附近。** 这样下一层拿到的输入永远是"正常大小"的。

### LayerNorm vs RMSNorm

**LayerNorm**（老方案）：
```
1. 减均值：x - mean(x)
2. 除标准差：/ std(x)
3. 乘可学习 γ，加可学习 β
```

**RMSNorm**（新方案，Llama/Qwen 用）：
```
1. 算 RMS = sqrt( mean(x²) )
2. 除以 RMS：x / RMS
3. 乘可学习 γ（没有 β）
```

差别：RMSNorm 不减均值。理由：更快（少算均值，省 10-20%），效果几乎一样。

> 项目配置：200M 用 LayerNorm，600M/1.5B 用 RMSNorm。不影响理解，原理都是"把数字拉回正常范围"。

### pre-norm vs post-norm（更重要）

```
post-norm（原始 Transformer）：     pre-norm（现代模型，本项目用）：
  x → [子层] → +x → [Norm]           x → [Norm] → [子层] → +x
```

**pre-norm 的好处**：子层拿到的输入永远是归一化过的（稳定），算完通过残差加回 x。x 这条主干道始终是干净的信号通道。**深层网络（28 层以上）几乎只能用 pre-norm，否则训不动。**

### 关键洞察：残差主干道是"干净"的

```
x (主干道)
│
├──────────────────────────┐  ← 残差旁路（x 直达）
│ [Norm]                   │
│ [Attention]              │  ← 子层只处理"一小份"信号
└──────────────────────────┘
│ + （加回主干）
▼
新的 x（主干道继续）
```

x 这条主干道，从第 1 层到第 30 层，数值一直是稳定的。每层子层只对"归一化后的一小份"做处理，结果加回主干。即使子层输出乱跳，主干道也不受太大影响。

> 类比一条大河（主干道 x），每层只是往里汇入一条小溪（子层输出）。小溪再浑浊，大河整体是稳的。**深层网络能训起来，不是归一化单独的功劳，是"归一化 + 残差"组合保证了主干道稳定。**

### 实际训练中会遇到的问题

- **Loss 突然变成 NaN**：通常是学习率太大、没归一化、或 fp16 数值溢出。→ fp16 + GradScaler 对付这个。
- **Loss 降不下去**：学习率太小，或某层梯度消失。
- **Loss 震荡**：batch 太小或学习率太大。

## 10. 完整流程串联

用「分久必合」走一遍完整流程：

```
「分久必合」4 个字
    │  embedding（每个字 → 704 维向量，随机初始化，训练中学出含义）
    ▼
4 个 704 维向量
    │  ┌───────────── Block × 30 ─────────────┐
    │  │                                       │
    │  │  x → [RMSNorm] → [Attention + RoPE]   │  ← 让字之间交流
    │  │              ↑ 旋转注入相对位置         │    （跨位置）
    │  │              └→ + x（残差）            │
    │  │                                       │
    │  │  x → [RMSNorm] → [SwiGLU FFN]         │  ← 每个字独立加工
    │  │              └→ + x（残差）            │    （逐位置）
    │  └───────────────────────────────────────┘
    ▼
4 个 704 维向量（已融合上下文 + 多层抽象）
    │  final norm + lm_head（704 → 32768）
    ▼
logits [4, 32768] → softmax → 概率分布
    │  和"下一个字"算交叉熵
    ▼
loss → backward → 更新参数
```

**各组件职责：**

| 组件 | 职责 | 性质 |
|---|---|---|
| **Attention** | 跨位置信息流动（让「合」看到「分」） | 靠学习（W_Q/K/V） |
| **RoPE** | 注入相对位置（让分数感受距离） | 靠设计（固定旋转，无可学习参数） |
| **FFN** | 逐位置非线性加工（1856 个模式探测器） | 靠学习（W_gate/up/down） |
| **RMSNorm + 残差** | 维持主干道稳定（深层能训） | 半设计（结构）半学习（γ） |

## 11. 关键认知总结

### 关于"学习"的本质

1. **没有任何维度被预先指定含义**——所有含义都是训练塑造的（embedding、头分工、FFN 探测器）。
2. **含义是涌现的，不是设计的**——像进化雕塑眼睛，loss 压力 + 海量数据把随机参数雕塑成有用结构。
3. **没有人"保证"合理**——我们至今没有严格理论证明这套架构一定能学出好表示。我们知道的是经验事实：容量 + 数据 + 优化压力 = 涌现。

### 关于"设计"的作用

4. **"模型能学" ≠ "设计无所谓"**——模型能在任何架构上学，但好架构让模型学得更快、更稳、泛化更远。
5. **大部分组件靠涌现，少数组件靠设计**——位置编码（RoPE）是少数设计真正重要的地方，数学性质决定上限（尤其是长度外推）。

### 关于 RoPE 的精确理解

6. **RoPE 是调制，不是解码**——位置项 (m−n)θ 塞进余弦函数里和内容角度加在一起，分数是内容和位置的不可分离混合物。
7. **没有基准，也不需要基准**——模型的任务不是"拆解分数"，而是"产生有用的分数"。通过学习 Q/K 方向，让混合后的分数在正确距离上给高/低值。
8. **RoPE 保证相对性，不保证可解码性**——分数只随相对距离变化，和绝对位置无关。

### 关于训练稳定性

9. **深层能训起来 = 归一化 + 残差**——归一化保证子层输入稳定，残差保证主干道信号直达。两者缺一不可。
10. **pre-norm 是深层网络必需**——28 层以上几乎只能用 pre-norm。
